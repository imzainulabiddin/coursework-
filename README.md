# Software Construction – Coursework

This repository contains my assignments, lab tasks, and projects for the **Software Construction** course.

## 📌 Course Overview

Software Construction focuses on the practical side of building high-quality software. It covers how to write clean, maintainable, and testable code, apply design principles, use version control, test and debug programs, refactor code, and work with build tools and collaboration workflows.

## 📚 Topics Covered

- Software development life cycle (SDLC)
- Coding standards and clean code
- Object-oriented programming principles
- SOLID principles and design patterns
- Unit testing and Test-Driven Development (TDD)
- Debugging and refactoring
- Version control with Git and GitHub
- Build tools and dependency management
- Continuous integration basics
- Code reviews and documentation
- Software quality and maintainability

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/imzainulabiddin/coursework.git
   ```

3. Follow the instructions in that folder’s `README.md`.
4. Run the code using your IDE or terminal.
